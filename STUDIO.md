# Astra Studio

The cloud worker renders original 1080×1920, 30 fps motion graphics, with genre-specific scenes, local Kokoro narration, phrase captions, an original procedural score and transitions. Music ducks under narration. Videos use H.264, AAC stereo and normalized loudness. Narration failure stops production rather than uploading a silent substitute.

The existing topic library, trend matching, upload controls and performance collection continue to apply. Studio records renderer version, duration, scene count and voice in performance.json for future comparisons. It does not measure audience retention or guarantee increased views. Current captions follow each spoken sentence, with approximate phrase timing.

Model files are fetched from the fixed upstream release and SHA-256 verified. ONNX telemetry is disabled before importing its runtime. Speech is processed on the runner; no narration API key is required.

## Validation

`python -m unittest discover -s tests -p 'test_studio.py' -v`

`python studio_renderer.py --preview /tmp/astra-preview.mp4`

Code pushes run tests and a full narrated preview before the read-only channel diagnostic. Scheduled jobs continue with the existing upload rules.

## Third-party components

- Kokoro-82M model: Apache-2.0, https://huggingface.co/hexgrad/Kokoro-82M
- kokoro-onnx: MIT, https://github.com/thewh1teagle/kokoro-onnx
- ONNX Runtime: MIT, https://github.com/microsoft/onnxruntime
- Voice model release: https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.1
- DejaVu fonts: https://dejavu-fonts.github.io/License.html

These dependencies retain their upstream licenses. Model binaries are cached on the runner and are not committed to this repository. The visuals and score are generated by the project's own renderer.
