ASTRA YOUTUBE CLOUD SETUP

CORE UPLOAD AUTOMATION (already used by the worker)

1. Required GitHub Actions secrets:
   YOUTUBE_CLIENT_ID
   YOUTUBE_CLIENT_SECRET
   YOUTUBE_REFRESH_TOKEN

2. The workflow runs every hour. Astra itself decides whether an upload attempt is due.
   Initial adaptive target: 9 uploads/day.
   Configured ceiling: 24 attempts/day.
   YouTube's own limits always take priority.

OPTIONAL OWNER ANALYTICS (recommended)

If your existing analytics_token.json is on the PC:
   python youtube_autonomy_setup.py --install-existing-analytics

This installs YOUTUBE_ANALYTICS_REFRESH_TOKEN automatically when the GitHub CLI
is already authenticated. It enables watch-time, average-view-percentage and
audience-retention learning.

FULL AUTONOMY PERMISSION

To also allow Astra to reply conservatively to clearly positive comments:
   python youtube_autonomy_setup.py --authorize-full

Google will open one owner-consent page. The resulting refresh token is installed
as YOUTUBE_FULL_REFRESH_TOKEN when possible. This one-time consent cannot be
legitimately bypassed because YouTube requires youtube.force-ssl for comment writes.

DO NOT:
- paste OAuth refresh tokens into chat
- commit client_secret.json, token.json or analytics_token.json
- use fake engagement, bought views or disposable-account tricks
